# MATH 565 webpage conventions

Follow the authoritative shared
[`classlib` webpage style guide](../classlib/docs/webpage-style.md) and
[`classlib` agent guidance](../classlib/AGENTS.md). This document records only
MATH 565 audience, terminology, logistics, and intentional local exceptions.

## Audience and writing

- Write for graduate students studying Monte Carlo and quasi-Monte Carlo
  methods.
- Introduce specialized probability, statistics, and numerical-analysis
  terminology before relying on it.
- Keep notation and terminology consistent with the MATH 565 slides and
  notebooks.

## Course terminology

- Use **course repository** for the GitHub source and **course website** for
  the published website.
- Avoid **class repository**, **class website**, and the shorthand **repo** or
  **site** in student-facing prose when the fuller term prevents ambiguity.
- Use literal filenames in inline code when they matter; otherwise prefer a
  descriptive link label.

## Semester-specific information

- Mark genuinely unresolved Fall 2026 information as `TBA` rather than
  inventing details or leaving a misleading blank.
- Cross-link authoritative schedule, assignment, test, project, notebook, and
  policy pages instead of copying details that could diverge.
- Link a notebook only after its target exists and passes validation.

## Local exceptions

MATH 565 currently has no general visual or structural exception to the shared
webpage style guide. Record a future exception here only when the course
genuinely requires behavior that should not apply to other consumers.
