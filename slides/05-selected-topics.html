Parallel computing

Practice

Modern CPUs and GPUs can evaluate many operations concurrently

  • Monte Carlo function values are often pleasingly parallel: samples can be evaluated independently
  • Parallel random-number streams must remain nonoverlapping and statistically sound
  • GPU arithmetic is often optimized for 32-bit floating point rather than 64-bit floating point
  • Reduced precision may lose significant digits but can increase throughput substantially
  • GPUs help most when there are many similar operations
    Launch and data-transfer costs can dominate small problems

Parallelism changes computational cost

It does not repair biased estimators or poor sampling designs

Reading the CPU/GPU experiment

  • Read speedup as CPU time / GPU time: above one favors the GPU
  • Name the baseline: NumPy CPU64, NumPy CPU32, or Torch CPU32
    The ratio compares complete implementations, including their random generators
  • Small jobs can favor CPUs; larger jobs spread fixed GPU overhead over more work
  • Generation can dominate: inspect stage timings before attributing a gap to evaluation

End-to-end time determines the practical gain

In the saved M3 Max run, at 262144 points the Torch CPU32 generation diagnostic is 25.196 ms versus 0.719 ms for evaluation; MPS is 0.507 ms versus 0.928 ms. Evaluation alone does not explain the complete-run GPU advantage. These stage medians exclude input conversion/transfer and are not an additive breakdown of the complete runs. Timings are illustrative, machine-specific measurements. CPU and GPU core counts do not predict their speedup ratio.

Faster computation and statistical accuracy

Compare a baseline and a faster implementation: single-core / multicore CPU, or CPU / GPU
For fixed sampling method; runtime proportional to sample count

\[\begin{equation*} \left. \begin{aligned} s=\frac{\operatorname{time}_{\mathrm{baseline}}(n)}{\operatorname{time}_{\mathrm{faster}}(n)}>1 &\quad\implies\quad n_{\mathrm{faster}}\approx s\,n_{\mathrm{baseline}}\\ \operatorname{error}(n)\approx A n^{-p} &\quad\implies\quad \frac{\operatorname{error}(n_{\mathrm{faster}})}{\operatorname{error}(n_{\mathrm{baseline}})}\approx\frac1{s^p} \end{aligned} \right\} \quad\begin{gathered}\alerttext{for the same}\\\alerttext{time budget}\end{gathered} \end{equation*}\]

Error: RMSE for IID/RQMC; absolute-error bound for QMC

Method Power \(p\) Conditions
IID \(1/2\) Finite contribution variance
QMC \(\approx1\) Sufficient smoothness and a suitable design
RQMC \(\approx3/2\) Sufficient smoothness and suitable scrambling

Speedup \(s=16\): about \(1/4\) of the IID RMSE, \(1/16\) of the QMC bound, \(1/64\) of the RQMC RMSE

Assume negligible floating-point error and comparable variance, and ignore setup/overhead in the same-time calculation. Float32 can eventually impose a numerical error floor; the saved experiment does not locate that floor. time_baseline(n)/time_faster(n) compares the time for the same n contributions. In the throughput regime, time is approximately proportional to sample count, so speedup s permits s times as many points at the same time budget. For a model error(n) approximately A n^{-p}, the ratio is s^{-p}. Keep the sampling method, integrand, and error constant A comparable between implementations. IID uses RMSE sigma/sqrt(n); deterministic QMC uses an absolute-error bound, not RMSE over randomizations or a ratio of actual errors. The displayed QMC/RQMC powers suppress logarithmic factors and are illustrative, not universal guarantees. QMC requires the smoothness/variation assumptions of its bound and a suitable point design. Smooth-integrand RQMC rates near n^{-3/2} require an appropriate randomization, such as nested uniform scrambling of suitable digital nets; a generic random shift does not ensure that rate. For replicated RQMC, keep the number of replications fixed. The s=16 examples use the nominal powers 1/2, 1, and 3/2. This applies to single-core versus multicore CPU implementations as well as CPU versus GPU implementations; name the actual baseline in either case. Total sample count controls sampling error; batch size controls memory and throughput. At fixed batch size, speedup can level off as both runtimes become proportional to n. Eight replications give a noisy empirical RMSE; a lucky point does not rank precision. In the M3 fixed-n sweep, changing batches from 4096 to 262144 reduces GPU runtime from 34.22 to 3.92 ms without changing n=1048576 or its IID error law. Larger batches need not always help; choose using measurements and memory limits.

Computing many expectations together

  • Reuse one sample batch across many functions to share generation cost and expose matrix work
  • More expectations add outputs; each expectation still uses the same \(n\) samples
  • Shared inputs give correlated estimates; their spread is not a standard error
  • Batch samples and functions to bound memory; measure the useful workload and backend

More outputs can improve throughput without improving accuracy per output

In the saved M3 Max run, 512 expectations take 56.8 ms on MPS: 16.4 times faster than NumPy CPU64, 6.3 times faster than NumPy CPU32, but only 2.0 times faster than Torch CPU32. The named baseline materially changes the conclusion. Small many-expectation timings are nonmonotone; do not infer a universal crossover or cause from three repetitions. Centers are added in order, changing the functions in the collection; mean absolute error across them is not a convergence curve. Independent whole-run replications are needed to assess sampling uncertainty. Keep the existing M3 measurements when editing prose.

Two-level Monte Carlo

Estimation

Take the fine approximation \(f_{d_2}(\vX_{1:d_2})\) as the target; larger dimensions cost more
Illustrative work per evaluation: \(\$(f_d)\propto d\)

  • Computational finance: \(d=\) time steps \(\times\) number of assets
  • ODE/PDE models with random fields: \(d=\) grid points representing the field

Choose \(d_1\ll d_2\) and couple the coarse and fine approximations

\[\begin{align*} Y_1&=f_{d_1}(\vX_{1:d_1})& &\text{cheap approximation}\\ Y_2&=f_{d_2}(\vX_{1:d_2})-f_{d_1}(\vX_{1:d_1})& &\text{expensive correction} \end{align*}\]

\[ \mu_{d_2}=\Ex\{f_{d_2}(\vX_{1:d_2})\}=\Ex(Y_1)+\Ex(Y_2) \]

Estimate the cheap part often and the expensive correction less often, if its error is easier to control

The two-level target is the finite fine mean mu_d2. Approximation bias relative to a limiting target mu is introduced separately in the hierarchy section. The displayed linear cost is an illustrative model for evaluation, not a universal dimension law. Cost includes input generation, transforms, and evaluation; dense factorizations or other solvers can cost more than O(d). In finance, d can count the scalar random inputs for a time-by-asset path discretization. In a random-field ODE/PDE model, d can count field values on a grid; the field-generation and solver costs need not be linear in d. A complete coupled correction costs roughly the fine evaluation plus any coarse work that cannot be reused. Its cost is typically of order d2 in this illustrative setting, whereas the cheap level costs order d1. Within Y2, coarse and fine approximations share a path or compatible inputs. For time discretizations, construct the coarse increments from fine ones; do not run an unrelated coarse path. Between the two level estimators, use independent samples or independent RQMC randomizations. A small mean correction does not imply a small variance or a small QMC error constant. Coupling should make the correction easier to integrate; that property, together with the cost ratio, must justify two levels.

Two-level notation: error and work

For the cheap part \(Y_1\) and coupled correction \(Y_2\), use \(\ell=1,2\)

Symbol Meaning
\(\mu_\ell=\Ex(Y_\ell)\), \(\hmu_\ell\) True level mean and its estimate
\(n_\ell\) Total contribution evaluations at level \(\ell\)
\(A_\ell\) Method-specific error amplitude in \(A_\ell n_\ell^{-p}\)
\(p>0\) Common error-decay power as the point count increases
\(\$_\ell\) Work for one complete level-\(\ell\) contribution
\(w_\ell\) Relative point-count weight: \(n_\ell\propto w_\ell\); work weights are \(\$_\ell w_\ell\)
\(\varepsilon\) RMSE or absolute-error tolerance relative to \(\mu_{d_2}\)
\(C=n_1\$_1+n_2\$_2\) Total work; held fixed when choosing the allocation

Random methods use RMSE; deterministic QMC uses an absolute-error bound

IID/RQMC: \(w_\ell=(A_\ell^2/\$_\ell)^{1/(2p+1)}\); deterministic weights follow their error bound

All work is measured in consistent units. A contribution evaluation includes its required inputs and transforms; the correction includes both coarse and fine evaluations, allowing any legitimate reuse. A_l and p depend on the integration method and level integrand. Only IID gives A_l^2=Var(Y_l). For RQMC with fixed replication count, n_l counts all evaluated points across runs. Later C(epsilon) denotes this same total work as a function of tolerance, not a second kind of cost. Setup/pilots and integer rounding are separate from this introductory linear-work model.

Random two-level estimates: IID or RQMC

Estimate \(\mu_\ell=\Ex(Y_\ell)\) with uncorrelated level means: \(\operatorname{cov}(\hmu_1,\hmu_2)=0\)
Independent sample sets \(\{Y_{i,1}\}_{i=0}^{n_1-1}\) and \(\{Y_{i,2}\}_{i=0}^{n_2-1}\) ensure this condition

\[\begin{align*} \hmu&=\hmu_1+\hmu_2& \hmu_\ell&=\frac1{n_\ell}\sum_{i=0}^{n_\ell-1}Y_{i,\ell}\\ \var(\hmu)&=\var(\hmu_1)+\var(\hmu_2)& C&=n_1\$_1+n_2\$_2 \end{align*}\]

For unbiased level estimates, model \(\operatorname{RMSE}(\hmu_\ell;\mu_\ell)\approx A_\ell n_\ell^{-p}\)

\[ \operatorname{MSE}(\hmu;\mu_{d_2}) =\var(\hmu) \approx\frac{A_1^2}{n_1^{2p}}+\frac{A_2^2}{n_2^{2p}} \]

  • IID: \(p=1/2\), \(A_\ell^2=\var(Y_\ell)\); the variance model is exact
  • RQMC: \(p\) and \(A_\ell\) depend on smoothness, design, and randomization
    Points within each sample set may be dependent

The MSE here is relative to the finite fine target mu_d2. Use a positive common exponent p for this allocation model and positive amplitudes A_l. Different levels can have different rates; the common-p formulas are a simplifying model, not a claim that all rates agree. For RQMC, Y_il are values from a randomized design with the correct marginals. Unbiasedness is assumed, and the variance is over design randomizations. Variance addition requires Cov(hmu1,hmu2)=0; independence is sufficient, not necessary. The explicitly indexed sample sets can be generated independently between levels, with independent RQMC randomizations. Within-level points may be dependent. The algebraically defined Y1 and Y2 need not be uncorrelated when evaluated on the same path; the zero-covariance condition is on their separately sampled level means. Within the correction Y2, retain the coarse/fine coupling. With a fixed number R of independent runs per level, n_l can denote total evaluations; absorb fixed replication factors into A_l and keep cost per evaluation consistent. More explicitly, n_l=R N_l and Var(mean of R runs) approximately a_l^2 N_l^{-2p}/R, so the amplitude in total-count notation is A_l=a_l R^{p-1/2}. Keep R fixed when varying n_l. Smooth integrands under suitable scrambling may have p near 3/2, ignoring logarithmic factors; a generic random shift does not guarantee that rate.

Allocating work optimally

Estimation

For independent unbiased random estimates, minimize the MSE model

\[ \frac{A_1^2}{n_1^{2p}}+\frac{A_2^2}{n_2^{2p}} \quad\text{subject to}\quad n_1\$_1+n_2\$_2=C \]

The optimal continuous allocation satisfies

\[ \frac{n_1}{n_2} =\left(\frac{A_1^2\$_2}{A_2^2\$_1}\right)^{1/(2p+1)} \]

For IID, \(p=1/2\) and \(A_\ell^2=V_\ell=\var(Y_\ell)\), recovering

\[ \frac{n_1}{n_2}=\sqrt{\frac{V_1\$_2}{V_2\$_1}} \]

More points for larger error amplitude; fewer for larger cost per point

For positive amplitudes and costs, differentiate the Lagrangian: \(2p A_\ell^2 n_\ell^{-(2p+1)}=\lambda\$_\ell\). The common factor \(2p\) cancels in the ratio. This is exact optimization of the continuous power-law model; RQMC power laws are generally approximations. At p=1/2 the optimal IID MSE is \((\sqrt{V_1\$_1}+\sqrt{V_2\$_2})^2/C\), as in the original IID treatment. Round to positive admissible sample sizes; RQMC may require powers of a base. Include setup and pilot costs in practical work. Pilot estimates of IID variance do not automatically identify RQMC amplitudes or rates; use whole randomized estimates and justify the applicable model.

Deriving the two-level allocation

Treat \(n_1,n_2>0\) as continuous; fix total work \(C\)

\[ \mathcal L=\frac{A_1^2}{n_1^{2p}}+\frac{A_2^2}{n_2^{2p}} +\lambda(n_1\$_1+n_2\$_2-C) \]

\[\begin{align*} \frac{\partial\mathcal L}{\partial n_\ell}=0 &\implies\frac{2pA_\ell^2}{n_\ell^{2p+1}}=\lambda\$_\ell \qquad(\ell=1,2)\\ \frac{A_1^2}{\$_1n_1^{2p+1}} &=\frac{A_2^2}{\$_2n_2^{2p+1}} \implies\frac{n_1}{n_2} =\left(\frac{A_1^2\$_2}{A_2^2\$_1}\right)^{1/(2p+1)} \end{align*}\]

Set \(w_\ell=(A_\ell^2/\$_\ell)^{1/(2p+1)}\); the budget gives

\[ n_\ell=\frac{Cw_\ell}{\$_1w_1+\$_2w_2} \]

At the optimum, each level buys the same marginal MSE reduction per unit work

Differentiate the MSE model, not RMSE, since their minimizers agree. The magnitude of the derivative with respect to work on level ell is 2p A_ell^2/(cost_ell n_ell^(2p+1)). If these marginal gains differ, transfer a little work toward the level with the larger gain. For p>0 and positive amplitudes and costs, the objective is strictly convex and diverges at either boundary of the feasible budget segment; the stationary point is the unique global continuous minimum. RQMC still uses an approximate variance model. Round up to allowed counts when targeting a tolerance; the fixed-budget continuous solution may need adjustment for admissible sizes.

Two-level cost as a function of error

Take \(d_2\) as the target dimension: \(\mu_{d_2}=\Ex\{f_{d_2}(\vX_{1:d_2})\}\)
Fix \(d_1,d_2\), amplitudes, and costs; require \(\operatorname{RMSE}(\hmu;\mu_{d_2})\le\varepsilon\)

\[ S=\$_1w_1+\$_2w_2 =\sum_{\ell=1}^2 A_\ell^{2/(2p+1)}\$_\ell^{2p/(2p+1)} \]

Substitute \(n_\ell=Cw_\ell/S\) into the MSE model

\[\begin{align*} \operatorname{MSE}_{\mathrm{opt}}(C)&\approx\frac{S^{2p+1}}{C^{2p}}\\ \operatorname{RMSE}_{\mathrm{opt}}(C)&\approx\frac{S^{p+1/2}}{C^p} \implies C(\varepsilon)\approx S^{1+1/(2p)}\varepsilon^{-1/p} \end{align*}\]

IID: \(p=1/2\), \(A_\ell^2=V_\ell\), so the continuous model gives exactly

\[ C(\varepsilon)=\frac{\left(\sqrt{V_1\$_1}+\sqrt{V_2\$_2}\right)^2}{\varepsilon^2} \]

Use the identity A_ell^2 w_ell^(-2p)=cost_ell w_ell to simplify the substituted MSE sum to S(2p+1)/C(2p). All formulas omit setup, pilots, and integer or design-size rounding. Per instructor request, this calculation concerns error relative to the fixed fine approximation mu_d2 only. Deterministic bounds are treated next.

What does reducing the error cost?

For the fixed two-level random-error model, \(C(\varepsilon)\propto\varepsilon^{-1/p}\)

\[ \frac{C(\varepsilon/r)}{C(\varepsilon)}\approx r^{1/p} \qquad(r>1) \]

Error-decay power Halve the RMSE Divide the RMSE by \(10\)
IID: \(p=1/2\) \(4\times\) total work \(100\times\) total work
Illustrative RQMC: \(p=1\) \(2\times\) total work \(10\times\) total work

IID example: \(V_1=16\), \(V_2=1\), \(\$_1=1\), \(\$_2=16\)

\[ C(\varepsilon)=64\varepsilon^{-2} \qquad C(0.1)=6400\quad C(0.05)=25600 \]

For IID, two levels can lower the cost constant; halving sampling error still costs four times as much

These ratios compare total work in separate runs, not additional work. Halving IID sampling RMSE requires three times the original work in addition to the original budget, for four times total. Tenfold reduction requires 99 times additional work. With nested reusable IID samples one can extend the original run accordingly. No reuse assumption is needed for the ratios. The numerical allocation is n1/n2=16, so at epsilon=0.1 use n1=3200,n2=200; at epsilon=0.05 use n1=12800,n2=800. Both levels get half the work. At C=3200, the later exercise gives RMSE=sqrt(0.02), consistent with this curve. RQMC p=1 is illustrative, not guaranteed; fixed replication factors are in A. A direct fine IID estimator also has epsilon^-2 sampling cost; compare its variance-times-cost constant with 64 before claiming an MLMC saving.

Deterministic two-level estimates

Use QMC separately for the same cheap part and coupled correction

Assume justified absolute-error bounds with a common \(p>0\)

\[\begin{align*} \abs{\hmu_\ell-\mu_\ell}&\le\frac{A_\ell}{n_\ell^p}\\ \abs{\hmu-\mu_{d_2}} &\le\abs{\hmu_1-\mu_1}+\abs{\hmu_2-\mu_2} \le\frac{A_1}{n_1^p}+\frac{A_2}{n_2^p} \end{align*}\]

At fixed work \(n_1\$_1+n_2\$_2=C\), minimize the bound

\[ w_\ell=\left(\frac{A_\ell}{\$_\ell}\right)^{1/(p+1)} \qquad\frac{n_1}{n_2}=\frac{w_1}{w_2} =\left(\frac{A_1\$_2}{A_2\$_1}\right)^{1/(p+1)} \]

QMC needs sufficient smoothness and a suitable design
Bound total error by the sum of the level error bounds

This is a triangle-inequality upper bound, not a sum-of-variances identity or an equality for the realized integration error. No independence or unbiasedness is asserted for deterministic estimates. Minimize the stated upper bound, not the unknown actual error. Differentiation gives \(p A_\ell n_\ell^{-(p+1)}=\lambda\$_\ell\) and the displayed ratio. A_l here is a deterministic error-bound amplitude, not the RQMC amplitude or the contribution SD. For a suitable RKHS bound it may be a discrepancy rate constant times the variation of the complete level integrand. An illustrative rate is p near 1 with appropriate smoothness and design; retain logarithmic factors if needed. A small correction variance alone does not guarantee a small deterministic QMC error amplitude. This bound is relative to the finite fine target mu_d2. Limiting-target approximation bias is treated separately in the hierarchy section.

What two levels accomplish

Estimation
  • \(d_1\ll d_2\): the coarse approximation can be much cheaper
  • Coupling can make the expensive correction easier to integrate
  • Allocate points using the error amplitudes, rates, and complete evaluation costs
  • IID/RQMC: independent unbiased level estimates add variances
  • Deterministic QMC: level error bounds add by an inequality
  • Fix the target dimension \(d_2\); increase \(n_1,n_2\) to control integration error

Two levels help when the cheap approximation and small correction error earn their combined cost

The correction must be small in the sense relevant to the integration method: variance for IID, randomized-estimate error amplitude for RQMC, and a justified variation/discrepancy bound for deterministic QMC. Neither a small correction mean nor pointwise closeness alone establishes all these properties.

Allocate two levels: points versus work

For independent IID level means, take \(p=1/2\) and total work \(C=3200\)

Quantity Cheap level 1 Correction level 2
Contribution variance \(V_\ell\) \(16\) \(1\)
Cost per contribution \(\$_\ell\) \(1\) \(16\)

\(\exstar\) Find the optimal ratio \(n_1/n_2\) and the point counts \(n_1,n_2\) How much work goes to each level? Do fewer correction samples imply less correction work?

The optimal IID ratio is \(\sqrt{V_1\$_2/(V_2\$_1)}=16\). The budget gives \(n_1+16n_2=3200\), so \(n_1=1600\) and \(n_2=100\). A hierarchy of coupled approximations

Estimation

Suppose

\[ \mu=\lim_{d\to\infty}\Ex\{f_d(\vX_{1:d})\} \]

as in an option payoff based on an increasingly fine time discretization

Choose \(d_1<\cdots<d_L\) and define coupled differences

\[\begin{align*} Y_1&=f_{d_1}(\vX_{1:d_1})\\ Y_\ell&=f_{d_\ell}(\vX_{1:d_\ell}) -f_{d_{\ell-1}}(\vX_{1:d_{\ell-1}}), \qquad 2\le\ell\le L \end{align*}\]

Then

\[ \mu_{d_L}=\Ex\{f_{d_L}(\vX_{1:d_L})\} =\sum_{\ell=1}^L\mu_\ell \qquad\mu_\ell=\Ex(Y_\ell) \]

with a remaining approximation bias \(b_L=\mu-\mu_{d_L}\)

Many levels

Estimation

Extend the same mean decomposition: \(\mu_{d_L}=\sum_{\ell=1}^L\mu_\ell\), \(\mu_\ell=\Ex(Y_\ell)\)

\[ \hmu=\sum_{\ell=1}^L\hmu_\ell, \qquad C=\sum_{\ell=1}^Ln_\ell\$_\ell \]

Independent unbiased IID/RQMC level estimates

\[ \operatorname{MSE}(\hmu;\mu_{d_L})=\sum_{\ell=1}^L\var(\hmu_\ell) \approx\sum_{\ell=1}^L\frac{A_\ell^2}{n_\ell^{2p}} \]

Deterministic QMC level estimates

\[ \abs{\hmu-\mu_{d_L}}\le\sum_{\ell=1}^L\abs{\hmu_\ell-\mu_\ell} \le\sum_{\ell=1}^L\frac{A_\ell}{n_\ell^p} \]

Choose both the level decomposition and the point allocation

Here mu_dL is the mean of the finest approximation in the preceding hierarchy; Y1 is the cheap output, and Y_l for l>=2 is a coupled correction. Each level mean is hmu_l=(1/n_l) sum_{i=0}^{n_l-1} Y_{i,l}, as in the two-level estimator. Sample indices start at zero; level indices start at one. The identity needed here is a decomposition of means; independent level sample sets need not form a single shared telescoping path. The same symbol A_l denotes the amplitude appropriate to the displayed case, not a claim that deterministic bounds and random RMSEs have equal constants. The independent randomized variance identity is exact; the common-p power law is a model. The deterministic statement requires actual justified bounds. For IID, p=1/2 and A_l^2=Var(Y_l), recovering sum_l V_l/n_l exactly.

Optimal multilevel allocation

Estimation

Use relative point-count weights \(w_\ell\) to extend the two-level ratios

Error criterion Allocation weight \(w_\ell\)
Independent IID/RQMC MSE model \(\displaystyle\left(A_\ell^2/\$_\ell\right)^{1/(2p+1)}\)
Deterministic QMC error bound \(\displaystyle\left(A_\ell/\$_\ell\right)^{1/(p+1)}\)

For total work \(C\), normalize the weights

\[ n_\ell=\frac{Cw_\ell}{\sum_{k=1}^Lw_k\$_k} \]

Point counts are proportional to \(w_\ell\); work shares are proportional to \(\$_\ell w_\ell\)

Allocate by error decay and cost; use the criterion appropriate to the method

These are continuous optimum counts for positive amplitudes, costs, and a common exponent p>0. Deterministic weights minimize the chosen upper bound, not the unknown realized error. Randomized weights minimize the MSE model. For IID the power-law variance model is exact. Different level exponents require solving the multiplier equations with those exponents instead. Round up to admissible counts and account for setup/pilot costs in practice. A zero-amplitude level, if known exactly, should be treated separately. For IID the resulting optimal MSE is \((\sum_\ell\sqrt{V_\ell\$_\ell})^2/C\).

Why telescoping helps

Estimation

Coupling can reduce correction error while finer evaluations cost more

Use geometric rate models \(A_\ell^2\propto\beta^\ell\), \(\$_\ell\propto\rho_{\mathrm{cost}}^\ell\), with \(\rho_{\mathrm{cost}}>1\)

At the optimal allocation, work per level satisfies

\[ \operatorname{work}_\ell=n_\ell\$_\ell \propto A_\ell^{2/(2p+1)}\$_\ell^{2p/(2p+1)} \propto(\beta\rho_{\mathrm{cost}}^{2p})^{\ell/(2p+1)} \]

  • \(\beta\rho_{\mathrm{cost}}^{2p}<1\): finer contributions receive less work
    The level sum stays bounded; the one-level integration RMSE rate \(C^{-p}\) can be retained
  • \(\beta\rho_{\mathrm{cost}}^{2p}>1\): finer contributions require more work
    Adding levels introduces a growing work penalty
  • IID (\(p=1/2\)) recovers the condition \(\beta\rho_{\mathrm{cost}}<1\)

For fixed \(L\), integration RMSE has rate \(C^{-p}\) in both regimes
The penalty grows as bias control requires more levels

Assume 0<beta<1, rho_cost>1, a common p>0, and positive constants of proportionality independent of level. These are illustrative geometric models, rather than only one-sided bounds, so they justify the less/more work interpretation. With only upper amplitude and cost bounds, the displayed geometric expression is a majorant; its growth does not prove actual fine-level dominance. Rho_cost is a real-valued cost-growth factor, not an integer sample index or the exponent in a sample count n=2^m. For IID A_l^2 is contribution variance; for RQMC it is the squared amplitude in the complete randomized-estimate error model, not contribution variance. At fixed C and L, the work normalizer is shared across levels. Thus the ratio of work on consecutive levels is (beta rho_cost{2p}){1/(2p+1)}. Writing \(S=\sum_\ell A_\ell^{2/(2p+1)}\$_\ell^{2p/(2p+1)}\), optimal integration RMSE is modeled by \(S^{p+1/2}C^{-p}\). When the geometric factor is below one, S remains bounded as L increases; above one, it grows with L. For fixed L both cases have the same C^{-p} power. A worse overall error power can arise only when tighter accuracy also increases L to control bias. If \(\abs{b_L}\lesssim B_{\mathrm{bias}}\rho_{\mathrm{bias}}^{-L}\) with rho_bias>1, and a fixed fraction of the error budget is assigned to bias, then L grows like log(1/epsilon)/log(rho_bias). Above the threshold the continuous model predicts \(C(\varepsilon)\approx\varepsilon^{-1/p}(\beta\rho_{\mathrm{cost}}^{2p})^{L/(2p)}\), with an effective error exponent \(p/[1+\log(\beta\rho_{\mathrm{cost}}^{2p})/(2\log\rho_{\mathrm{bias}})]<p\). A full complexity bound must also include the finest-level cost forced by minimum admissible counts, setup, pilots, and rounding. The one-level-rate claim assumes those costs and the bias can also be controlled within that rate.

Why telescoping helps: deterministic QMC

Assume justified level bounds \(\abs{\hmu_\ell-\mu_\ell}\le A_\ell n_\ell^{-p}\)

Model error-bound amplitudes by \(A_\ell\propto\theta^\ell\) and cost by \(\$_\ell\propto\rho_{\mathrm{cost}}^\ell\)

At the bound-minimizing allocation, work per level satisfies

\[ \operatorname{work}_\ell=n_\ell\$_\ell \propto A_\ell^{1/(p+1)}\$_\ell^{p/(p+1)} \propto(\theta\rho_{\mathrm{cost}}^p)^{\ell/(p+1)} \]

  • \(\theta\rho_{\mathrm{cost}}^p<1\): finer contributions receive less work
    The level sum stays bounded; the one-level integration-error bound rate \(C^{-p}\) can be retained
  • \(\theta\rho_{\mathrm{cost}}^p>1\): finer contributions require more work
    Adding levels introduces a growing work penalty
  • For the illustrative QMC rate \(p=1\), the condition is \(\theta\rho_{\mathrm{cost}}<1\)

As bias control requires more levels, coupling must preserve smoothness and reduce QMC error-bound amplitudes

Assume 0<theta<1, rho_cost>1, p>0, and level-independent proportionality constants. Theta describes decay of A_l itself; the random slide’s beta describes decay of A_l^2. These are different method-dependent amplitudes. If the same amplitude sequence were used in both models, beta would be theta^2. The consecutive-level work ratio is (theta rho_costp){1/(p+1)}. Writing \(S_{\mathrm Q}=\sum_\ell A_\ell^{1/(p+1)}\$_\ell^{p/(p+1)}\), the optimized deterministic bound is \(S_{\mathrm Q}^{p+1}C^{-p}\). Below the threshold the sum stays bounded; above it, refinement adds a growing factor. As in the random case, fixed L gives C^{-p} in both regimes. If a justified bias model \(\abs{b_L}\lesssim B_{\mathrm{bias}}\rho_{\mathrm{bias}}^{-L}\) sets L from the tolerance, the growing-factor regime predicts continuous work \(C(\varepsilon)\propto\varepsilon^{-1/p}(\theta\rho_{\mathrm{cost}}^p)^{L/p}\), with effective error exponent \(p/[1+\log(\theta\rho_{\mathrm{cost}}^p)/\log\rho_{\mathrm{bias}}]<p\). These predictions concern the chosen deterministic bound, not equality for the realized error. Include minimum allowed counts, setup/pilots, rounding, and logarithmic factors before claiming a complete complexity rate. A_l is a justified deterministic bound amplitude, for example a discrepancy rate constant times the correction integrand’s variation. Small IID variance or a small correction mean does not establish this bound or its decay.

Cost for a multilevel error tolerance

Let \(\mu_{d_L}=\Ex\{f_{d_L}(\vX_{1:d_L})\}\) and \(b_L=\mu-\mu_{d_L}\)
Write \(C(\varepsilon)\) for the total work required at error tolerance \(\varepsilon\)

For independent unbiased IID/RQMC level estimates

\[ \operatorname{MSE}(\hmu;\mu)=b_L^2+\sum_{\ell=1}^L\var(\hmu_\ell) \approx b_L^2+\sum_{\ell=1}^L\frac{A_\ell^2}{n_\ell^{2p}} \]

Choose \(L\) with \(b_L^2<\varepsilon^2\); set \(\varepsilon_{\mathrm s}^2=\varepsilon^2-b_L^2\)

With optimal continuous allocation, ignoring setup and rounding

\[ C(\varepsilon)\approx\varepsilon_{\mathrm s}^{-1/p} \left[\sum_{\ell=1}^L A_\ell^{2/(2p+1)}\$_\ell^{2p/(2p+1)} \right]^{1+1/(2p)} \]

IID (\(p=1/2\)): \(C(\varepsilon)\approx\varepsilon_{\mathrm s}^{-2}\left(\sum_\ell\sqrt{V_\ell\$_\ell}\right)^2\)

The MSE-bias decomposition is exact for unbiased independent level estimates; the power-law variance expression is a model and is approximate for RQMC. The per-contribution cost \(\$_\ell\) charges for generating inputs and evaluating the complete coupled difference. Coupling within a correction does not violate independence between entire level estimates. Write \(S=\sum_\ell A_\ell^{2/(2p+1)}\$_\ell^{2p/(2p+1)}\). The optimal allocation has \(n_\ell=C(A_\ell^2/\$_\ell)^{1/(2p+1)}/S\), giving modeled MSE \(S^{2p+1}/C^{2p}\). Solving for cost at RMSE epsilon_s gives the displayed expression. For IID p=1/2, A_l^2=V_l, and this is the original variance-times-cost formula. For one unbiased level, cost is approximately \(\$_1(A_1/\varepsilon)^{1/p}\). For RQMC keep replication counts fixed and match the amplitude to the count convention used on the two-level slide. The bias usually needs a justified bound or estimate. The displayed ideal bias budget does not discover it. L, amplitudes, and costs can depend on epsilon, so epsilon_s^{-1/p} alone is not the full complexity rate. Round up to positive admissible design sizes, with bounded rounding ratios, and include setup, pilot, and bias-assessment costs in actual work. Sources: Giles (2015) and Giles and Waterhouse: multilevel QMC.

Deterministic multilevel error budget

With justified QMC level bounds, include approximation bias by an inequality

\[ \abs{\hmu-\mu}\le\abs{b_L}+\sum_{\ell=1}^L\frac{A_\ell}{n_\ell^p} \]

Choose \(L\) with \(\abs{b_L}<\varepsilon\); set \(\varepsilon_{\mathrm s}=\varepsilon-\abs{b_L}\)

Minimizing the bound gives a sufficient work estimate, allowing rounding

\[ C(\varepsilon)\lesssim\varepsilon_{\mathrm s}^{-1/p} \left[\sum_{\ell=1}^L A_\ell^{1/(p+1)}\$_\ell^{p/(p+1)} \right]^{1+1/p} \]

Random errors combine through variances; deterministic bounds combine through the triangle inequality

Let \(S_{\mathrm Q}=\sum_\ell A_\ell^{1/(p+1)}\$_\ell^{p/(p+1)}\). At cost \(C\) the minimized continuous bound is \(S_{\mathrm Q}^{p+1}/C^p\). A sufficient continuous budget is therefore \(C=\varepsilon_{\mathrm s}^{-1/p}S_{\mathrm Q}^{1+1/p}\); rounding to allowed sizes multiplies cost by a bounded factor, absorbed in lesssim. This is an upper bound on work needed to guarantee the stated accuracy under the assumed level error bounds, not the unknown actual minimum cost or an equality for the realized error. The bound requires suitable smoothness and designs. Unknown QMC amplitudes cannot be inferred from IID sample variance alone. Include setup/pilot work, positive sample minima, logarithmic terms, and epsilon-dependent L and amplitudes as appropriate, just as in the single-level QMC cost discussion.

Where the cost exponent changes: IID/RQMC

Assume \(\abs{b_L}\lesssim B_{\mathrm{bias}}\rho_{\mathrm{bias}}^{-L}\), with \(\rho_{\mathrm{bias}}>1\)
A fixed bias fraction gives \(L\approx\log(1/\varepsilon)/\log\rho_{\mathrm{bias}}\)

Write \(G=\beta\rho_{\mathrm{cost}}^{2p}\); in the continuous allocation model

\[ C(\varepsilon)\propto\varepsilon^{-1/p} \left[\sum_{\ell=1}^LG^{\ell/(2p+1)}\right]^{(2p+1)/(2p)} \]

Level-work regime Exponent \(q\) in \(C(\varepsilon)\propto\varepsilon^{-q}\)
\(G<1\): less work on finer levels \(\displaystyle\frac1p\)
\(G>1\): more work on finer levels \(\displaystyle\frac1p+\frac{\log G}{2p\log\rho_{\mathrm{bias}}}\)

The exponent grows beyond \(1/p\) when bias-driven refinement adds fine-level work

Minimum allowed samples also add work of order \(\varepsilon^{-\log\rho_{\mathrm{cost}}/\log\rho_{\mathrm{bias}}}\)

Ignore the borderline G=1. Use the geometric models on the telescoping slide, with fixed p and level-independent constants, and a fixed split between bias and sampling error. Constants in B_bias and the bias fraction only shift L by a bounded amount. The displayed L is the selected level count from the bias bound; it need not be the smallest L the actual unknown bias permits. For G<1 the geometric sum is bounded above and below by positive constants. For G>1 it is proportional to G^{L/(2p+1)}. Raising to (2p+1)/(2p) gives \(G^{L/(2p)}\propto\varepsilon^{-\log G/(2p\log\rho_{\mathrm{bias}})}\). Thus the continuous model has cost exponent q=1/p in the first regime and \(q=1/p+\log G/(2p\log\rho_{\mathrm{bias}})\) in the second. Error decays like total work to power -1/q once bias is included through the selected L. The evaluation work added by a minimum allowed design on every level scales as sum_l cost_l, hence exponent q_floor=log(rho_cost)/log(rho_bias). With bounded-factor rounding, the modeled rounded evaluation-work exponent is max(q,q_floor). Setup and pilot work must also be counted. These are model predictions for allocation, not unconditional finite-sample error guarantees.

Where the cost exponent changes: deterministic QMC

Use the same bias model and \(L\approx\log(1/\varepsilon)/\log\rho_{\mathrm{bias}}\)

Write \(H=\theta\rho_{\mathrm{cost}}^p\); use the continuous deterministic bound model

\[ C(\varepsilon)\propto\varepsilon^{-1/p} \left[\sum_{\ell=1}^LH^{\ell/(p+1)}\right]^{(p+1)/p} \]

Level-work regime Exponent \(q\) in sufficient work \(C(\varepsilon)\propto\varepsilon^{-q}\)
\(H<1\): less work on finer levels \(\displaystyle\frac1p\)
\(H>1\): more work on finer levels \(\displaystyle\frac1p+\frac{\log H}{p\log\rho_{\mathrm{bias}}}\)

A growing level sum adds \(\log H/(p\log\rho_{\mathrm{bias}})\) to the tolerance exponent

Minimum allowed samples again add work of order \(\varepsilon^{-\log\rho_{\mathrm{cost}}/\log\rho_{\mathrm{bias}}}\)

Ignore the borderline H=1. The deterministic bound amplitudes follow the geometric model A_l proportional to theta^l; they are not random variances. Above the threshold the level sum is proportional to H^{L/(p+1)}. Raising to (p+1)/p gives H^{L/p}, yielding the displayed extra epsilon power. C(epsilon) here is the sufficient work selected by minimizing the specified bound, not an equality for the unknown minimal work or the realized error. The same minimum-design-work exponent q_floor applies; bounded-factor rounding gives max(q,q_floor) for modeled evaluation work. Add setup and pilot work before quoting a complete practical complexity rate.

Allocate randomized work in practice

  • Time complete coupled contributions at each level; estimate \(\$_\ell\)
    Include generation, transforms, and both coarse/fine evaluations
  • IID pilots: estimate \(V_\ell\) from individual outputs; use \(p=1/2\), \(A_\ell^2=V_\ell\)
  • RQMC pilots: fix \(R\) independent runs and vary the points \(N_\ell\) per run
    Estimate variance \(\hat v_\ell(n_\ell)\) of the reported level mean; total point count \(n_\ell=RN_\ell\)

For a justified rate \(p\), estimate the amplitude by

\[ \widehat{A_\ell^2}\approx n_\ell^{2p}\hat v_\ell(n_\ell) \]

  • For RQMC, fit \(p\) from variance decay versus point count across several sizes
  • Use the amplitude and cost estimates in the allocation weights; round to allowed sizes
  • Charge for the pilot; use fresh independent final runs after choosing the counts

For IID, the usual sample variance divided by n_l estimates the variance of the reported level mean. For RQMC, repeat the entire N_l-point design with independent randomizations. If R runs with N_l points per run are averaged, the across-run sample variance divided by R estimates the variance of the reported mean, and the total point count in the displayed convention is n_l=R N_l. Keep R fixed when comparing point counts and in the A_l model. Under an approximate power law, at a fixed level use a generic total count n. Comparing n and a larger allowed rn gives \(\hat p_\ell=\log[\hat v_\ell(n)/\hat v_\ell(rn)]/(2\log r)\). Several counts and replications are preferable to treating one noisy ratio as an established rate. If levels have different rates, do not force the common-p closed form: use the level-specific multiplier equations or a measured marginal variance-reduction-per-work allocation. Timing needs the complete coupled contribution and a representative batch; separate fixed setup from per-point cost and include GPU synchronization. Freeze allocation after an independent pilot for a simple final analysis. Adaptive reuse needs its own unbiasedness and uncertainty justification. Source: Giles, Multilevel Monte Carlo methods (2015).

Validate the remaining error budget

  • Deterministic QMC: obtain \(A_\ell,p\) from justified smoothness, discrepancy, or coefficient-tail bounds
    Differences between point counts are diagnostics; they do not by themselves certify an error bound
  • Approximation bias: choose \(L\) using a justified refinement-error bound or model
    A small final correction alone does not bound the entire omitted tail
  • Pilot uncertainty: rare contributions and noisy replication variances can mislead allocation
  • Complete work: include setup, pilots, minimum sample counts, and allowed design sizes

Pilot estimates guide allocation; accuracy claims need justified error and bias assessments

For deterministic QMC, the relevant error amplitude may be difficult to know or estimate. Use a theoretical bound or a validated a posteriori procedure under its stated assumptions, such as justified coefficient-decay conditions; do not reinterpret an IID sample SD as a deterministic QMC bound. For approximation bias, a mean correction can help fit a convergence model, but a bound on the sum of omitted corrections needs assumptions on the remaining hierarchy. Quantify uncertainty in estimated correction means and model parameters. Do not choose L merely because one noisy correction is small. Independent RQMC replication supports variance estimation; very small R does not by itself support a reliable confidence interval or a finite-sample coverage guarantee. The pilot/amplitude model is for allocation and planning, not an automatic stopping certificate.

Gradient descent

Estimation

For

\[ \vtheta_* = \argmin_{\vtheta\in\reals^m}\operatorname{Loss}(\vtheta), \]

gradient descent iterates

\[ \vtheta_{k+1}=\vtheta_k-\eta_k\nabla\operatorname{Loss}(\vtheta_k) \]

  • \(\eta_k\) is the step size or learning rate
  • The loss often decreases toward a local minimum
  • Curvature-aware methods can use second derivatives
    Each step becomes more expensive
  • Step sizes that are too large may overshoot
    Step sizes that are too small converge slowly

Move downhill using all available data

Stochastic gradient descent

Estimation

Suppose

\[ \operatorname{Loss}(\vtheta) =\sum_{i=0}^{N-1}\operatorname{loss}_i(\vtheta) \]

Computing the full gradient costs \(N\) component gradients

Stochastic gradient descent uses an inexpensive random component:

\[ \vtheta_{k+1}=\vtheta_k-\eta_k\nabla\operatorname{loss}_{I_k}(\vtheta_k), \qquad I_k\sim\Unif\{0,\ldots,N-1\} \]

Common variants include

  • decaying learning rates
  • mini-batch gradients
  • mini-batches with decay

The stochastic gradient is cheap but noisy
Averaging a mini-batch reduces its variance

Choose an action by simulating futures

Monte Carlo
Tree Search

At the current state, choose an action with a high expected return

  • A node represents a state or decision history; branches represent possible actions
  • A simulator generates possible continuations and their rewards
  • Grow the tree where additional simulations are most useful
  • Applications include game moves and sequential planning

Monte Carlo estimates guide which action to take and where to search next

MCTS means Monte Carlo tree search, not Markov chain tree search. It is a sequential-decision and search method, distinct from MCMC target sampling. For this introduction use a finite-horizon, single-agent planning problem with bounded rewards and a simulator for state transitions. A return is the sum of future rewards, with discounting if specified. A fixed rollout policy estimates its own continuation value, not automatically the optimal value; continued tree expansion and improved decisions matter. Stochastic transitions can be represented by chance nodes or sampled within the simulator. Source: Kocsis and Szepesvari (2006).

One tree-search iteration

Monte Carlo
Tree Search
Step What happens
Select Follow branches using estimated returns and exploration bonuses
Expand Add an untried action or a new node when possible
Simulate Complete a rollout to a terminal state or chosen horizon
Backpropagate Update visit counts and average returns along the traversed path

Repeat until the simulation budget is exhausted, then choose a root action

Allocate simulations adaptively; avoid exploring every branch equally

Backpropagation here means updating tree statistics, not differentiating through a neural network. Each ancestor uses the return appropriate to its position on the path, including rewards and discounting when relevant. Terminal states skip expansion and rollout. A truncated rollout may use a value approximation, adding modeling error. A common final choice is the most visited root action; distinguish that decision rule from the exploratory selection rule used during tree growth. Parallel rollouts are possible, but MCTS is a search strategy with its own separate teaching purpose.

Exploration versus exploitation

Monte Carlo
Tree Search

An illustrative UCT selection score for visited actions is

\[ \overline Q(s,a)+c\sqrt{\frac{\log N(s)}{N(s,a)}} \qquad c>0 \]

  • \(\overline Q(s,a)\): estimated return — exploit promising actions
  • \(N(s)\) and \(N(s,a)\): state and action visit counts
  • The bonus favors less visited actions — explore uncertain alternatives

For \(N(s)=60\) and \(c=0.2\),

Action \(N(s,a)\) \(\overline Q(s,a)\) Selection score
A 40 0.70 0.764
B 10 0.60 0.728
C 10 0.68 0.808

\(\exstar\) Which action gets the next simulation, and why is it different from the largest estimated return?

Choose C, despite A having the largest current mean. Its exploration bonus is about 0.128 versus about 0.064 for A. Visit untried actions before applying the formula so no division by zero occurs. The natural logarithm is used; rewards are scaled to [0,1] for this illustration. UCT means upper confidence bounds applied to trees. The exploration parameter c depends on reward scale and the chosen UCT convention. This is an illustrative selection score, not a confidence interval for an arbitrary adaptively generated tree return. Tree return distributions evolve as the search policy changes; ordinary IID standard-error reasoning does not automatically apply. Original UCT results require assumptions such as bounded rewards and finite-horizon or discounted planning. No finite-budget optimal-action guarantee is claimed. Source: Kocsis and Szepesvari, Bandit based Monte-Carlo Planning (2006).
